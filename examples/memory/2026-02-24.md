# 每日日志示例

## 10:15 记忆系统调研
- 调研了 5 个 OpenClaw 记忆方案：官方 QMD、Engram、Calicastle 三层、Mem0、Supermemory
- 结论：采用官方 QMD + Calicastle 三层 cron 架构的融合方案
- Mem0/Supermemory 不适合个人 Agent 场景（过重/SaaS 锁定）
- Engram 功能强但过重，cron 方案已覆盖核心需求

## 14:00 融合方案配置
- 安装 QMD：`bun install -g https://github.com/tobi/qmd`
- 配置 memory.backend = "qmd" + session transcript 索引
- 创建 3 个 cron job：hourly/daily/weekly
- 更新 AGENTS.md 记忆规则

## 16:30 搜索工具测试
- grok-search：内容质量高但稳定性一般（遇到 503）
- tavily search：速度快且稳定，适合 fallback
- 确定搜索优先级：grok-search → tavily → web_fetch → browser
